# イラストを描く

写真がないとき、記事の内容に合うイラストを SVG（図形を組み合わせた画像のファイル）で描いて載せる。
CLAUDE.md の進め方（提案 → OK → 保存）に沿って進める。

## 1. 提案（描く前に言葉で確認する）

記事の完成案と一緒に、イラストの内容を **言葉で** 提案する。

- 何を描くか（例:「展示会のブースで、緑のエプロンを着た2人のスタッフが来場者に説明している様子。後ろに観葉植物とパネル」）
- 雰囲気・季節・色の印象（例:「明るく、サイトの緑に合わせた色」）
- 載せる場所（本文のどこに入れるか）
- 「写真ではなくイラストです」と明記する

OKが出たら描く。担当者が「おまかせ」と言ったら、記事の内容から考えてそのまま描いてよい。

## 2. 描く

保存先：`site/assets/img/news/`
ファイル名：`news_記事のフォルダ名_内容.svg` の形（例: `site/assets/img/news/news_20261105_booth.svg`）。半角の英小文字・数字・ハイフン・アンダーバーだけを使う。
Write でファイルを直接作る。

### 決まりごと（守らないとチェックで止まる）

- いちばん外側は `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1600 900">`（横長 16:9）
- `width`・`height` は書かない（ページの幅に合わせて自動で伸び縮みさせるため）
- 使えるのは図形だけ：`rect`、`circle`、`ellipse`、`line`、`polyline`、`polygon`、`path`、`g`、`defs`、`linearGradient`、`radialGradient`、`stop`、`clipPath`、`use`（`href="#名前"` のみ）
- 使えないもの：`script`、`image`、`a`、`foreignObject`、アニメーション、`on〜` 属性、外部ファイルの読み込み
- ファイルサイズは 500KB まで（目安は 30〜150KB）

### 絵柄の決まり（サイト全体で見た目をそろえるため）

- **フラットなイラスト**：線画ではなく、塗りの図形を重ねる。影やグラデーションは控えめに（空や背景のグラデーション程度）
- **色**：サイトの色に合わせる。`site/assets/style.css` の先頭（`:root`）にある **メインの緑**（`--green`）・**薄い緑**（`--green-bg`）・**文字の色**（`--ink`）を基本にし、内容に合う落ち着いた色を3〜4色足す。原色やネオンカラーは使わない
- **人物**：顔の細かい描写はせず、丸い頭と簡単な体で表す。特定の実在の人物に似せない
- **文字は入れない**：画像の中に文字を書かない（読めない・直せないため。看板やパネルは無地の図形にする）
- **使えない題材**：実在の会社・展示会・団体のロゴやマーク、既存のキャラクター、実在の建物そっくりの絵
- 背景を画面いっぱいに描き、主役（人物や物）は中央付近に置く。端に大事なものを置かない（スマートフォンでは小さく表示される）

## 3. 見た目を確かめる（必ず行う）

```
python tools/render_svg.py site/assets/img/news/ファイル名.svg
```

- チェックでエラーが出たら直して、もう一度実行する
- 書き出された確認用の画像（`/tmp/issue-images/check-ファイル名.png`）を **Read で開いて見る**
- 図形のずれ、はみ出し、人物や物が不自然に重なっていないか、提案した内容になっているかを確かめ、おかしければ直してもう一度確かめる（直すのは2回まで。それでも難しければ、図形の数を減らしてシンプルにする）

## 4. 記事に使う

- ニュースの本文（`news.json` の記事の `blocks`）に、画像のブロックとして入れる：`{ "t": "image", "v": "/assets/img/news/news_20261105_booth.svg", "alt": "〜のイラスト" }`
- `alt` の最後は必ず「イラスト」で終える（例: 「展示会のブースで来場者を迎える様子のイラスト」）
- `python tools/build.py --check` を実行してから保存する

## 5. 返事に書くこと

- 描いた内容の説明（1〜2文）
- 「確認用ページで、イラストの見た目も確かめてください」
- 直し方の例：「`@claude イラストの人を3人にして`」「`@claude イラストの季節を冬にして`」のように頼めば描き直すこと

## 描き直しを頼まれたとき

- まだ本番に公開していないイラストは、同じファイル名のまま描き直してよい
- すでに本番に公開されたイラストを描き直すときは、新しいファイル名（末尾に `-v2` など）で保存し、記事の画像ブロックの `v` を新しいファイル名に書き換える（ブラウザに古い画像が残る問題を防ぎ、古い画像を履歴として残すため）
- 描き直したら、もう一度「3. 見た目を確かめる」を行う
- 担当者が写真に差し替えたいときは、edit の手順書の「画像を追加・差し替える」に従う
